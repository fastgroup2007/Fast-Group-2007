# Fast Group — نسخة اللابتوب v6

نسخة الموقع الأخيرة، دون الحاجة إلى Android Studio أو Xcode أو npm. التنسيق مجمّع محليًا. تشمل البحث بالموديل، 67 موديلًا، التاريخ، المصروفات الإضافية، رابط التقييمات والواجهة المضغوطة للموبايل.

## التشغيل

فك الضغط، وثبّت Python إن لم يكن موجودًا ثم شغّل start-fast-group.bat على Windows. اتبع العنوان الذي يظهر. بيانات المتصفح لا تنتقل بمجرد نسخ ملفات الموقع؛ صدّر بياناتك قبل تغيير العنوان أو الاستضافة.

## رفع الكود على GitHub

1. سجل الدخول واختر New repository.
2. سمّه fast-group واختر Private لحفظ الكود بعيدًا عن العرض العام، أو Public لنشر المصدر.
3. أنشئ المستودع ثم اختر uploading an existing file، أو Add file → Upload files.
4. اسحب محتويات النسخة؛ يجب أن يكون index.html في جذر المستودع وليس داخل مجلد إضافي.
5. اكتب Update Fast Group v6 ثم Commit changes. إن طلب GitHub فرعًا جديدًا، أنشئه وافتح Pull request وادمجه بعد المراجعة.
6. للتحديث ارفع الملفات المعدلة بنفس مواقعها وأسمائها.

لا ترفع ZIP نفسه أو بيانات العملاء أو النسخ الاحتياطية أو كلمات المرور أو ملفات إعادة تعيين الدخول.

## تشغيل الموقع بعد حفظه

رفع الملفات إلى GitHub يحفظ الكود فقط. اربط المستودع باستضافة مناسبة للنشاط التجاري. ملف netlify.toml مرفق؛ مجلد النشر هو جذر الملفات، ولا توجد خطوة بناء مطلوبة لهذه النسخة.
