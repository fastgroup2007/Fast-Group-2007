# Fast Group — نسخة اللابتوب v6

نسخة الموقع الأخيرة، دون الحاجة إلى Android Studio أو Xcode أو npm. التنسيق مجمّع محليًا. تشمل البحث بالموديل، 67 موديلًا، التاريخ، المصروفات الإضافية، رابط التقييمات والواجهة المضغوطة للموبايل.

## التشغيل

فك الضغط، وثبّت Python إن لم يكن موجودًا ثم شغّل start-fast-group.bat على Windows. اتبع العنوان الذي يظهر. بيانات المتصفح لا تنتقل بمجرد نسخ ملفات الموقع؛ صدّر بياناتك قبل تغيير العنوان أو الاستضافة.

## رفع الكود على GitHub

1. سجل الدخول واختر New repository.
2. سمّه fast-group واختر Private لحفظ الكود بعيدًا عن العرض العام، أو Public لنشر المصدر.
3. أنشئ المستودع ثم اختر uploading an existing file، أو Add file → Upload files.
4. اسحب محتويات النسخة؛ يجب أن يكون index.html في جذر المستودع وليس داخل مجلد إضافي.
5. اكتب Update Fast Group v6 ثم Commit changes. إن طلب GitHub فرعًا جديدًا، أنشئه وافتح Pull request وادمجه بعد المراجعة.
6. للتحديث ارفع الملفات المعدلة بنفس مواقعها وأسمائها.

لا ترفع ZIP نفسه أو بيانات العملاء أو النسخ الاحتياطية أو كلمات المرور أو ملفات إعادة تعيين الدخول.

GitHub Pages لا يسمح باستعماله كاستضافة مجانية لتشغيل النشاط التجاري أو مواقع مخصصة أساسًا لتسهيل المعاملات التجارية. لا تستخدمه لاستضافة النسخة التجارية الحية. السياسة: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## تحديث العملاء والمخزن — 27 سبتمبر 2026

- حفظ بيانات CRM والمرفقات في IndexedDB، مع نقل النسخة المحلية القديمة بعد حفظ نسخة احتياطية منها. لا يعيد التحديث تهيئة المخزن أو قاعدة البيانات.
- طابور حفظ دائم يعيد المحاولة عند عودة الاتصال؛ لا تعني رسالة الحفظ المحلي أن الخادم استلم التعديل. راقب شريط المزامنة.
- بطاقات العملاء والفواتير وصور الشغل والمشتريات تدعم اختيار عدة ملفات وإضافة المزيد، مع الاحتفاظ بالملف القديم. حد الملف الواحد 8 ميجابايت؛ لا يوجد حد برمجي لعدد الصور، وتظل سعة المتصفح محدودة.
- الصور والمستندات تظل خاصة بالمتصفح الذي رفعها ولا تُرفع إلى جدول site_state العام. زر النسخة الاحتياطية يشمل الصور. لا تمسح بيانات المتصفح قبل تنزيلها.
- الشغل السابق يدعم اسم الفني وصور الجهاز. الشغل المطلوب ينتقل بزر ✓ إلى الشغل المنفذ، مع البحث وفلاتر تاريخ التنفيذ وإمكانية الإرجاع.
- التسعير في المخزن: تجاري أو خصم 3% أو 4% أو 7% أو 8%. الأسعار القديمة لا تتغير تلقائيًا.
- وارد الأجهزة يسجل جهازًا واحدًا لكل سيريال، ويزيد الرصيد مرة واحدة. قراءة الصورة تقترح السيريال للمراجعة قبل الحفظ؛ الموديل يُختار أو يُكتب. تنزيل محرك القراءة يحتاج اتصالًا.
- لا توجد ترحيلات SQL ولا تغيير في سياسات RLS أو حسابات الدخول. الصلاحيات الحالية على الواجهة كما كانت؛ تأمين الخادم مستقل عن هذا التحديث.

التحقق: اختبارات متصفح ببيانات اصطناعية لحساب موظف وشاشة موبايل، امتلاء localStorage، مرفقات متعددة، الانتقال للمنفذ، التسعير، الوارد والسيريال المكرر، تعارض كتابة، والحفظ دون اتصال ثم إعادة الفتح. اختبر تكامل واجهة OCR بنتيجة اصطناعية؛ دقة القراءة الحقيقية تعتمد على الصورة. تم فحص مسار PATCH بخادم الإنتاج باستخدام شرط لا يطابق أي سجل، دون تغيير بيانات الإنتاج.
